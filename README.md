# 맘핏 (MomFit)

임신 주수에 맞춰 집에서 하루 5~30분 할 수 있는 임산부 홈트 웹앱.

- 상태별 추천 — 아침 / 식후 / 오래 앉은 뒤 / 자기 전 / 힘든 날 / 운동 부족
- 동작 20개, 자세별(서서·앉아서·옆으로 누워서·네발기기) 분류
- 케어 — 부담되는 곳 제외 설정 + 부위별 통증 완화 동작
- 플레이어 — 링 타이머, 준비 화면, 소리·진동 신호, 화면 꺼짐 방지
- 기록 — 주 150분(ACOG 권장) 대비 진행, 월 달력

단일 `index.html`. 빌드·의존성·외부 요청 없음. 데이터는 localStorage에만 저장.

## 의학적 근거

미국산부인과학회(ACOG) Committee Opinion 804(2020)와 영국 NHS 임신 중 운동 지침을 따릅니다.
**이 앱은 일반적인 정보 제공을 목적으로 하며 의학적 조언을 대신하지 않습니다.**
